# 📝 Reviews System for Juan Jovel's Website

## 🎯 Overview

This repository includes a seamless review system that allows collaborators, students, and colleagues to leave feedback about their experiences working with Juan Jovel. The system integrates GitHub Issues with a beautiful static website.

## 🌟 How It Works

### For Users Leaving Reviews:
1. **Visit the Reviews Page**: Navigate to the "Reviews" tab on Juan's website
2. **Click "Leave a Review"**: This takes you directly to GitHub with a pre-filled template
3. **Fill Out the Template**: Use the comprehensive review template to share your experience
4. **Submit**: Your review becomes a GitHub issue that Juan can review and respond to
5. **Optional Public Display**: With your permission, your review may be featured on the website

### For Juan (Website Owner):
1. **Receive Reviews**: Reviews come in as GitHub issues with the "review" label
2. **Review & Respond**: You can respond to reviews directly on GitHub
3. **Curate for Website**: Select the best reviews to display on your static site
4. **Maintain Quality**: The GitHub system keeps everything organized and searchable

- **Issue Template**: Pre-filled form for consistent review format
- **Labels**: Automatic "review" and "feedback" labels
- **Assignees**: Automatically assigned to you for easy tracking
